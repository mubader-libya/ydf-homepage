# ربط الموقع بـ Strapi

الموقع جاهز ليقرأ محتواه من Strapi. هذا المجلد يحوي كل ما يحتاجه الخادم:
أنواع المحتوى، وصلاحيات القراءة العامة، وسكربت ينقل المحتوى الحالي.

## كيف يعمل

- الواجهة (ملفات HTML في جذر المستودع) تُرفع إلى `ydf.ly`.
- Strapi يعمل على نطاق فرعي، مثل `cms.ydf.ly`.
- في `site-config.js` يوضع رابط Strapi:
  ```js
  window.YDF_CONFIG = { cms: "https://cms.ydf.ly" };
  ```
- تطلب الصفحات الأنشطة من `/api/activities`. إن كان الحقل فارغاً أو تعذّر الوصول إلى Strapi، تعرض البيانات المحلية في `act-data.js`، فلا تظهر صفحة فارغة أبداً.

## مسارات الـ API

كل الطلبات في مكان واحد: `ENDPOINTS` داخل `sub.js`. لا توجد أي صفحة تطلب Strapi مباشرة.

| الاسم في الموقع | المسار في Strapi | الحقول المرتبطة | تستخدمه |
|---|---|---|---|
| `activities` | `GET /api/activities` | `cover`, `gallery`, `city`, `project` | `activities.html`، `activity.html` |
| `news` | `GET /api/news-items` | `cover`, `gallery` | `news.html`، `news-item.html` |

الصفحات تطلب بياناتها هكذا: `YDF.load("news")`. ولإضافة صفحة جديدة: أضف نوع المحتوى هنا في `strapi/src/api`، ثم مدخلاً في `ENDPOINTS` يحدد المسار، والحقول المرتبطة، والبيانات المحلية، ودالة التحويل.

## أنواع المحتوى

| النوع | الحقول | يظهر في |
|---|---|---|
| **نشاط** `activity` | العنوان، التاريخ، النوع، المدينة، المشروع، النص (blocks)، صورة الغلاف، المعرض، `slug` اختياري، `legacyId` | صفحة الأنشطة وصفحة النشاط |
| **مشروع** `project` | الاسم، `key` (حروف إنجليزية صغيرة)، الوصف، الترتيب، «يظهر كخيط» | خيوط المشاريع، والورقة الجانبية |
| **مدينة** `city` | الاسم، خط العرض والطول، «خارج ليبيا»، الدولة، «الاسم ظاهر دائماً» | الخريطة وأزرار المدن |
| **خبر** `news-item` | العنوان، التاريخ، النوع (`statement` بيان، `meeting` لقاء، `project` مشاريع، `general` عام)، الجهة (للقاءات)، النص، الغلاف، المعرض، `legacyId` | صفحة الأخبار وصفحة الخبر |

قيم «نوع النشاط»، وما يقابلها في الموقع:

| القيمة | تظهر في الموقع |
|---|---|
| `dialogue` | جلسة حوارية |
| `training` | تدريب |
| `participation` | مشاركة |
| `community` | رياضة ومجتمع |
| `humanitarian` | عمل إنساني |
| `announcement` | إعلان |
| `meeting` | لقاء |

رابط النشاط في الموقع هو `activity.html?id=` متبوعاً بأول قيمة موجودة من هذه بالترتيب: `slug`، ثم `legacyId`، ثم `documentId`. الأنشطة المنقولة تحتفظ برقمها القديم في `legacyId`، فتبقى روابطها القديمة صالحة.

## التثبيت على الخادم (مرة واحدة)

يحتاج Node.js 20 أو أحدث.

1. أنشئ مشروع Strapi 5 جديداً:
   ```bash
   npx create-strapi@latest cms --no-example --js
   ```
2. انسخ محتوى `strapi/src` من هذا المستودع فوق `cms/src`. يشمل ذلك `src/api/*` و`src/index.js`.
3. قاعدة البيانات: SQLite يكفي للبداية، وفي الإنتاج يُفضّل PostgreSQL أو MySQL.
4. شغّل Strapi:
   ```bash
   npm run build && npm run start
   ```
   ثم ضعه خلف Nginx على `cms.ydf.ly` مع شهادة HTTPS، وأبقه يعمل باستمرار بـ pm2 أو systemd.
5. افتح `https://cms.ydf.ly/admin` وأنشئ حساب المدير الأول.

يمنح `src/index.js` الزوار صلاحية **القراءة فقط** للأنواع الأربعة تلقائياً عند كل تشغيل، فلا حاجة لضبطها يدوياً.

## نقل المحتوى الحالي

1. من لوحة Strapi، افتح Settings ثم API Tokens، وأنشئ مفتاحاً من نوع **Full access**. احذفه بعد انتهاء النقل.
2. شغّل الأمر من جذر هذا المستودع:
   ```bash
   STRAPI_URL=https://cms.ydf.ly STRAPI_TOKEN=المفتاح node strapi/scripts/import-content.mjs
   ```
   ينقل السكربت 14 مدينة و5 مشاريع و31 نشاطاً و39 خبراً مع صورها (نحو 355 صورة). تشغيله أكثر من مرة آمن، لأنه يتخطى ما نُقل من قبل.
3. ضع رابط Strapi في `site-config.js` وارفع الموقع.

## ملاحظات

- **الصور:** يولّد Strapi تلقائياً أحجاماً أصغر من كل صورة، والموقع يختار المناسب منها. الصور المرفوعة تُحفظ في `public/uploads` على الخادم، فاحرص على نسخها احتياطياً.
- **النشر:** الأنشطة والمشاريع تحتاج ضغط **Publish** حتى تظهر في الموقع. المدن تظهر فور حفظها.
- **CORS:** إعداد Strapi الافتراضي يسمح بالطلب من أي نطاق. لتقييده بنطاق الموقع وحده، ضع في `config/middlewares.js`:
  ```js
  { name: 'strapi::cors', config: { origin: ['https://ydf.ly'] } }
  ```
